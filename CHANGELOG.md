# Changelog

Todas as mudanças relevantes deste projeto são documentadas aqui.

## [1.0.0] - 2026-08-14

### Destaques
- Pipeline de analytics com dados oficiais da CONAB e dashboard executivo publicado via GitHub Pages.
- Métricas de concentração, Pareto, qualidade de dados, análises em Python/R e consultas SQL.
- Camada preditiva conservadora, com bloqueio explícito de modelos complexos quando o histórico é insuficiente.
- Workflow de CI para executar a suíte de testes a cada alteração.
